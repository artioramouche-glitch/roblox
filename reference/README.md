# Dossier `reference/`

Copies d'autres serveurs MCP Roblox importées dans ce dépôt. Elles sont **gardées pour consultation** et ne sont
**pas utilisées** par le build ni par les tests.

| Dossier | Contenu |
|---|---|
| `roblox-mcp-main/` | Ancienne base du dépôt (aaronaalmendarez/roblox-mcp v2.3) : serveur Node, plugin, workflow Rojo « Blueprint V1 », CLI `studio` |
| `studio-rust-mcp-server-main/` | Serveur MCP officiel de Roblox (Rust) |
| `roblox-studio-rust-mcp-server-main/` | Variante enrichie du serveur Rust (outils UI, simulation d'entrées…) |

Le serveur actif est dans `packages/` (base 6xvl + Game Kit) et le plugin dans `studio-plugin/`.
